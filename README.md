Calculadora de gastos, com o visual e estrutura feitas com o CSS3 e HTML5, e com a funcionalidade dos cálculos pelo JavaScript.
Site realizado para fins de estudos de estrutura código em POO, com Programação Funcional como utilização de funções de alta ordem (ex. find, reduce)
e função pura (quando não depende de variáveis externas, e sempre retorna o mesmo resultado se receber os mesmos argumentos).
